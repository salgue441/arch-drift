# Development phases

Incremental milestones. Prefer a git tag when a phase is stable (for example `phase-0-triangle`).

| Phase | Goal |
|-------|------|
| **0** | CMake + C++23, GLFW window, Vulkan colored triangle, validation when available, RAII / `Result` baseline, docs |
| **1** | Placeholder track + kart, follow camera, keyboard driving |
| **2** | Arcade drift / mini-turbo feel, sim unit tests, tunables |
| **3** | QR token session, HTTP + WebSocket controller, gyro + buttons |
| **4** | Laps / placements, small original item set, basic AI |
| **5** | Visual / audio polish and extra content |

Content expands without rewriting layer boundaries.
